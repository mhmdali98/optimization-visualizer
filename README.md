# Optimization Algorithms Visualizer

Interactive 2D + 3D visualization of four metaheuristic optimization algorithms:
Random Search, Hill Climbing, Simulated Annealing, and Tabu Search.

## Live Demo
https://mhmdali98.github.io/optimization-visualizer/

## Features
- 5 test functions (Rastrigin, Himmelblau, Ackley, Sphere, Egg-Holder)
- Real-time animation in both 3D landscape and 2D contour views
- Side-by-side comparison mode
- Tunable parameters per algorithm
- Click on 2D map to set start position

## Stack
Pure HTML/CSS/JS + Three.js r160 (via CDN). No build step.

## Run Locally
Open `index.html` in any modern browser. That's it.

## Educational Context
Built for a Metaheuristic Optimization course exploring "One Problem, Four Strategies".
